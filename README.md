# RM & Co. website

Public website for RM & Co., including the RM Digital business page.

## Current business lines

- RM Digital
- RM Mobility
- RM Capital
- RM Industrial

## Development

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
npm test
```

The site is deployed through OpenAI Sites using the project identifier in `.openai/hosting.json`.
